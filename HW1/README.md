1.a. Entity: клиент, тренер, абонемент, зал, тренировка, посещение.



клиент: client\_id, full\_name, phone

тренер: coach\_id, full\_name, specialization

абонемент: membership\_id, price, start\_date, end\_date, client\_id

зал: room\_id, room\_name, capacity

тренировка: training\_id, training\_name, duration, room\_id, coach\_id, datetime

посещение: visit\_id, client\_id, training\_id, attended



1.b. Relationship:



\-- клиент - абонемент (один к одному): один клиент имеет только один активный абонемент.

\-- клиент - посещение (один ко многим): один клиент имеет множество записей о посещениях.

\-- тренер - тренировка (один ко многим): один тренер может проводить много тренировок.

\-- зал - тренировка (один ко многим): в одном зале проходят разные тренировки.

\-- тренировка - посещение (один ко многим): одну тренировку посещают несколько человек.



2.a. Запрос 1: π (client\_id, end\_date) (σ(price < 10000 ∧ price > 6000) membership)

Вернуть таблицу со столбцами client\_id, end\_date, для таблицы membership, цена за абонемент которых находится в диапазоне (6000, 10000).



2.b. Запрос 2: room ⋈ σ(duration > 90) training



Объединить столбцы таблиц (получиться по room\_id), должно быть выполнено условие, что длительность тренировки больше 90 минут.
